THE SHORT VERSION

Why 18-bit?

Many displays use 6 physical bits for each red, green, and blue channel. That makes 64 × 64 × 64 — exactly 262,144 native colors.

Eight-bit values between native levels may be simulated by rapidly alternating pixels across frames (FRC). This picker only emits channel values divisible by four, so the panel can display them without temporal dithering.

Native 8-bit values: 0, 4, 8, 12 … 248, 252.
